Como apontar os 3 domínios na HostMF para esta VPS:
No painel DNS da HostMF de cada um dos 3 domínios, adicione um registro do Tipo A com Nome @ apontando para o IP da sua VPS. Os 3 domínios irão funcionar juntos no mesmo servidor sem custo extra!

4. Domínio do Atestado UPA 24h ★ Validação Oficial UPA
